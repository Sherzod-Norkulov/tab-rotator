# Tab Rotator — Политика конфиденциальности

Обновлено: 2026-04-28

## Что делает расширение
- Переключает вкладки по таймеру.
- По желанию открывает заданный список URL в отдельном окне.
- Сохраняет настройки (интервалы, список URL, профили) локально в браузере.

## Какие данные мы собираем
- **Ничего не отправляем на сторонние серверы.**
- Локально (в `chrome.storage.local`) сохраняются только ваши настройки: интервалы, список ссылок, профили, флаги автообновления, no-refresh списки, порядок переключения, задачи автообновления, тема интерфейса и состояние автозапуска.
- Расширение запрашивает доступ `tabs`, `storage` и `idle`, чтобы читать список открытых вкладок для переключения/обновления, сохранять настройки и опционально ставить ротацию на паузу по состоянию активности браузера.

## Обработка и хранение
- Все данные хранятся локально в браузере пользователя.
- Данные не передаются третьим лицам и не используются для идентификации пользователя.
