## [Unreleased]

## [1.4.0] — 2026-05-14

### Added
- Команды Chrome shortcuts: Toggle rotation и Stop rotation доступны через
  `chrome://extensions/shortcuts` без дополнительных permissions.
- Дублирование выбранного профиля и экспорт текущей конфигурации, если профиль
  не выбран.

### Changed
- Ротация теперь валидирует именно включённые (`Rotate`) и поддерживаемые цели,
  а не просто количество строк в списке.
- Автозаполнение списка открытых вкладок пропускает системные страницы браузера
  и страницы расширений.

### Fixed
- `Open list tabs before start = off` больше не обходится принудительным
  открытием недостающих вкладок при старте custom-list ротации.
- Service worker больше не сохраняет `isRunning: true`, если для старта
  недостаточно поддерживаемых целей.
- Автообновление не пытается перезагружать неподдерживаемые внутренние страницы.

## [1.3.0] — 2026-04-28

### Added
- Политика паузы ротации: никогда, при активности пользователя или при
  idle/locked состоянии браузера (`chrome.idle`). Во время паузы на бейдже
  показывается индикатор `⏸`.
- Независимые per-URL задачи автообновления текущей страницы с отдельным
  интервалом, списком активных задач и кнопкой сброса всех задач.
- No-refresh список доменов: страницы из этого списка не перезагружаются ни
  при ротации, ни независимыми задачами автообновления.
- Тёмная тема popup с локальным сохранением выбора.

### Changed
- Версия расширения поднята до `1.3.0` в `manifest.json`.
- Разрешения расширения дополнены `idle` для опциональной паузы по активности
  браузера; host permissions по-прежнему не запрашиваются.
- Профили и импорт/экспорт JSON сохраняют новые настройки `pausePolicy`,
  `noRefreshDomains` и `refreshTasks`.

## [1.2.0] — 2026-04-22

### Added
- Документация релизного цикла: `CHANGELOG.md`, `RELEASE.md` (процесс релиза),
  `QA_CHECKLIST.md` (ручной QA-чеклист перед публикацией в Chrome Web Store).
- Скрипт `scripts/package.sh` для сборки воспроизводимого релизного ZIP
  (`dist/tab-rotator-<version>.zip`), с валидацией обязательных файлов и
  исключением служебных каталогов.
- Подробный README: архитектура, установка unpacked, использование, сборка ZIP,
  отладка service worker и popup, troubleshooting, приватность.
- Валидация импортируемых JSON-профилей: проверка типа, формы, лимитов
  (512 KB на файл, 100 профилей, 500 записей на профиль, 4 KB на строку) и
  безопасная санитизация полей перед записью в `chrome.storage.local`.

### Changed
- Версия расширения поднята до `1.2.0` в `manifest.json`.
- README полностью переписан по фактическому состоянию проекта; устаревшие
  формулировки удалены.
- `STORE_LISTING.md`: удалено маркетинговое упоминание «встроенных» профилей
  Work/Monitoring/Reports — в расширении нет предустановленных профилей.
  Документ полностью переработан в финальный source-of-truth для Chrome
  Web Store (название, короткое и подробное описание, возможности, «Кому
  подойдёт», «Как начать», категория, языки, ссылки, «Что нового 1.2.0»,
  краткий блок про разрешения).
- Добавлен `CWS_SUBMISSION.md` — ответы для полей формы публикации в
  Chrome Web Store (single purpose, обоснование разрешений, data usage,
  краткое резюме конфиденциальности, заметка для GitHub Release,
  submission-чеклист).
- `PRIVACY_POLICY.md`: обновлена дата.

### Fixed
- `rotateTabs()` в режиме shuffle больше не обращается к `undefined`, если пул
  кандидатов неожиданно оказался пустым — безопасный fallback на
  последовательный выбор и пропуск тика, если переключаться не на что.
- `ensureDedicatedWindow()` больше не создаёт пустое окно `about:blank`, если
  список URL пуст или первая запись без URL.
- `tabMatches()` fallback ужесточён: убрана свободная `String.includes`-проверка,
  которая давала ложные совпадения на коротких целевых фрагментах. Остался
  только строгий сравнительный префикс.

### Internal
- `background.js`: fallback для `chrome.runtime.getManifest().version`
  переключён с жёстко зашитой строки версии на нейтральное значение `'0.0.0'`,
  чтобы версия расширения жила единственным источником истины в `manifest.json`.
- `chrome.runtime.onConnect`: поведение порта `'panel'` (standalone-окно popup)
  явно задокументировано — он намеренно не ставит ротацию на паузу.

## [1.1.0] — 2025-12-11

### Added
- Индивидуальные интервалы и задержка автообновления для записей списка.
- Отдельное окно мониторинга (`useDedicatedWindow`).
- Исключения по доменам (`excludeDomains`), режим `shuffle`.
- Бейдж обратного отсчёта на иконке (`badgeCountdown`).
- Опция «ротация при открытом popup» (`allowRotationWhilePopupOpen`).
- Профили с импортом/экспортом JSON.
- Локализации `en`, `ru`, `uz` через `_locales`.

## [1.0.0]

- Первая публичная версия: базовая ротация активной вкладки по общему интервалу.
