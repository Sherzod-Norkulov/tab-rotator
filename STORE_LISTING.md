## Подробное описание (поле Description)

```
Tab Rotator — расширение для Google Chrome, которое автоматически переключает
активную вкладку по заданному таймеру. Подходит, когда вам нужно поочерёдно
показывать на экране несколько страниц: дашборды мониторинга, графики, отчёты,
ленты или презентационный набор страниц на большом экране.

━━━ Что делает расширение ━━━

• Переключает вкладки в текущем окне по общему интервалу (в секундах).
• Поддерживает индивидуальный таймер для каждой страницы — например, одну
  показывать 10 секунд, другую 60.
• Автоматически обновляет выбранные страницы перед показом, с настраиваемой
  задержкой между обновлением и переключением.
• Может обновлять текущую страницу по отдельному per-URL интервалу даже без
  запуска ротации; все такие задачи можно сбросить одной кнопкой.
• Позволяет составить собственный список URL и использовать только его, а не
  все открытые вкладки.
• При желании открывает этот список в отдельном окне браузера, чтобы не
  трогать ваши рабочие вкладки.
• Поддерживает два порядка переключения — последовательный и случайный.
• Позволяет исключить домены, которые никогда не должны участвовать в
  ротации (например, рабочую почту).
• Позволяет отдельно указать домены, которые нельзя автообновлять.
• Может ставить ротацию на паузу при активности пользователя или при
  idle/locked состоянии браузера.
• Поддерживает тёмную тему popup.
• Показывает обратный отсчёт прямо на иконке расширения (бейдж можно
  отключить).
• Поддерживает автозапуск ротации при старте браузера.
• Позволяет сохранить любой набор настроек как профиль, быстро переключаться
  между профилями и переносить их между устройствами через экспорт и импорт
  JSON. Предустановленных профилей нет — вы создаёте их сами.
• Работает локально: никакие данные не отправляются на сторонние серверы.
• Интерфейс доступен на русском, английском и узбекском языках.

━━━ Как это работает ━━━

1. Нажмите на иконку Tab Rotator в панели браузера — откроется окно настроек.
2. Укажите интервал переключения в секундах.
3. При необходимости добавьте свой список страниц (кнопка
   «+ Добавить страницу»), задайте имя, URL, индивидуальный таймер и флаг
   автообновления для каждой записи.
4. Нажмите «Запустить». Расширение начнёт переключать вкладки.
5. Остановить ротацию можно той же кнопкой в попапе.
6. Чтобы сохранить текущую конфигурацию, используйте «Сохранить как» в блоке
   профилей. Дальше её можно быстро применять или экспортировать в файл.

━━━ Кому это полезно ━━━

• Дежурным инженерам и администраторам — автоматический показ набора
  дашбордов мониторинга на отдельном экране.
• Аналитикам — поочерёдный просмотр графиков, BI-панелей и отчётов.
• Офисам и digital signage — презентационный экран с набором страниц
  компании, расписаний, новостей.
• Преподавателям и докладчикам — смена контента на общем экране по таймеру
  без ручного переключения.
• Обычным пользователям — всем, кто хочет, чтобы вкладки сменяли друг друга
  сами, пока они заняты другими делами.

━━━ Приватность ━━━

Расширение не собирает персональные данные, не ведёт аналитику и не
обращается к сторонним серверам. Все настройки — интервалы, список URL,
профили, флаги — хранятся только локально в вашем браузере через стандартный
механизм chrome.storage.local.

━━━ Разрешения ━━━

• «tabs» — чтобы читать список открытых вкладок и переключаться между ними,
  а также открывать страницы из вашего списка в отдельном окне.
• «storage» — чтобы сохранять ваши настройки и профили локально.
• «idle» — чтобы опционально ставить ротацию на паузу по состоянию активности
  браузера.

Никаких host permissions, доступа к содержимому страниц и сетевых запросов
расширение не делает.

━━━ Открытый исходный код ━━━

Исходный код, политика конфиденциальности, changelog и инструкции доступны
в репозитории: https://github.com/Sherzod-Norkulov/tab-rotator
```

## Ключевые возможности

- Автоматическое переключение вкладок по таймеру.
- Общий интервал и индивидуальные таймеры для каждой страницы.
- Собственный список URL и возможность использовать только его.
- Открытие списка в отдельном окне браузера.
- Автообновление выбранных страниц с настраиваемой задержкой.
- Независимое автообновление текущей страницы по per-URL интервалу.
- No-refresh список доменов, где reload запрещён.
- Последовательный или случайный порядок переключения.
- Исключение доменов из ротации (с учётом поддоменов).
- Пауза ротации по активности пользователя или idle/locked состоянию.
- Тёмная тема popup.
- Обратный отсчёт на иконке расширения (можно отключить).
- Автозапуск ротации при старте браузера.
- Профили настроек с экспортом и импортом в JSON.
- Пауза ротации при открытом попапе (опционально отключается).
- Локальное хранение данных, без внешних серверов.
- Интерфейс на русском, английском и узбекском языках.

## Как начать

1. Установите расширение и нажмите на его иконку в панели Chrome.
2. В поле «Интервал переключения» укажите количество секунд между сменой
   вкладок.
3. Если нужна ротация только по своему списку — включите «Использовать
   только указанный список вкладок» и нажмите «+ Добавить страницу». Для
   каждой записи можно задать имя, URL, индивидуальный таймер и флаг
   «Обновлять».
4. Чтобы расширение открыло ваш список в отдельном окне, включите
   «Открывать список в отдельном окне».
5. Нажмите «Запустить». Остановить ротацию можно той же кнопкой.
6. Любой набор настроек можно сохранить как профиль кнопкой «Сохранить как»
   в блоке профилей и затем быстро применять или экспортировать в
   JSON-файл.

Подсказки:

- Поля «Исключить домены» и «Никогда не обновлять домены» принимают список через запятую, например:
  `mail.google.com, calendar.google.com`. Поддомены учитываются.
- Переключатель «Порядок» задаёт последовательный или случайный обход.
- В блоке «Автообновление текущей страницы» можно создать отдельную задачу
  обновления текущего URL и удалить все такие задачи кнопкой «Сбросить всё».
- Если не хотите видеть обратный отсчёт на иконке — выключите «Показывать
  таймер на иконке» в блоке «Дополнительно».

## Разрешения (краткий блок)

- **`tabs`** — чтение списка открытых вкладок и программное переключение
  активной вкладки, а также открытие страниц пользовательского списка в
  отдельном окне.
- **`storage`** — локальное хранение настроек и профилей пользователя в
  `chrome.storage.local`.
- **`idle`** — чтение только состояния активности браузера для опциональной
  паузы ротации; данные никуда не передаются.
- **Host permissions не запрашиваются.** Расширение не читает и не
  изменяет содержимое страниц, не внедряет скрипты, не выполняет сетевые
  запросы и не загружает удалённый код.

Полный текст обоснования разрешений для формы submission находится в
[`CWS_SUBMISSION.md`](CWS_SUBMISSION.md).
