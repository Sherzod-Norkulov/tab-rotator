# Tab Rotator

Chrome-расширение (Manifest V3) для автоматического переключения вкладок по таймеру.
Поддерживает общий интервал и индивидуальные таймеры для каждой записи, автообновление
страниц, независимые задачи автообновления текущей вкладки, профили с
импортом/экспортом, отдельное окно мониторинга, исключения по доменам,
паузы по активности/бездействию, тёмную тему, случайный порядок и бейдж
обратного отсчёта на иконке.

- **Версия:** 1.3.0
- **Manifest:** v3
- **Локализации:** `en`, `ru`, `uz` (через `_locales/`)
- **Permissions:** `tabs`, `storage`, `idle` (без host permissions)
- **Сборка:** без bundler — расширение загружается как unpacked из корня репозитория

## Возможности

- **Ротация вкладок по интервалу.** Переключение активной вкладки в текущем окне каждые
  N секунд (общий интервал) либо по индивидуальным таймерам для каждой записи.
- **Список открытых вкладок.** При первом открытии popup текущие вкладки уже
  подгружаются в список; список можно обновить кнопкой «Load open tabs».
- **Кастомный список URL.** Ротация только по заданному списку страниц; остальные
  вкладки не участвуют. Для каждой записи можно отдельно включить/выключить участие
  в ротации.
- **Автоматическое открытие недостающих вкладок.** Если страницы из списка ещё не
  открыты, расширение может открыть их автоматически перед запуском ротации.
  Если опция выключена, расширение больше не открывает вкладки принудительно и
  честно сообщает, что целей для ротации недостаточно.
- **Отдельное окно мониторинга.** Список открывается в выделенном окне, чтобы не
  мешать рабочим вкладкам.
- **Автообновление страниц.** Для отдельных записей можно включить `reload` при
  переключении, с опциональной задержкой.
- **Автообновление текущей страницы.** Отдельные per-URL задачи обновляют
  выбранные страницы по своему интервалу даже без ротации; все задачи можно
  сбросить одной кнопкой.
- **Исключения по доменам.** Список доменов (через запятую), которые исключаются из
  ротации (включая поддомены).
- **No-refresh список.** Отдельный список доменов защищает страницы от
  автообновления (например формы, банки, админки).
- **Порядок переключения.** Последовательный или случайный (`shuffle`).
- **Пауза по активности.** Ротацию можно не прерывать, либо ставить на паузу,
  когда пользователь активен, либо когда браузер idle/locked.
- **Профили.** Сохранение, переименование, удаление, применение, импорт/экспорт JSON.
  Выбранный профиль можно продублировать, а без выбранного профиля кнопка экспорта
  выгружает текущую конфигурацию как backup.
- **Тема день/ночь/авто.** Переключается из popup, сохраняется локально и в режиме
  `auto` следует системной теме браузера/ОС.
- **Бейдж обратного отсчёта.** Показывает секунды до следующего переключения на иконке
  расширения (можно отключить).
- **Автозапуск.** Ротация стартует автоматически при старте браузера, если включен
  `autoStart` и ротация была активна.
- **Пауза при открытом popup.** По умолчанию ротация ставится на паузу, пока открыт
  popup, и возобновляется при его закрытии. Поведение отключается чекбоксом
  «Rotate while popup is open».
- **Локализация.** Интерфейс и тексты статусов переведены через `chrome.i18n`.
- **Keyboard shortcuts.** В `chrome://extensions/shortcuts` доступны команды
  Toggle rotation и Stop rotation без дополнительных permissions.
- **Безопасные ограничения.** Ротация, автооткрытие и автообновление работают
  только с поддерживаемыми страницами `http:`, `https:` и `file:`; системные
  страницы браузера (`chrome://`, `edge://`, `about:`, `devtools://`) пропускаются.

## Архитектура

```
tab-rotator/
├── manifest.json           # MV3, permissions: tabs + storage + idle
├── background.js           # Service worker: таймеры, tabs/windows, storage, messaging
├── popup.html              # UI popup (инлайн CSS + разметка)
├── popup.js                # Логика popup: настройки, профили, сообщения в SW
├── _locales/
│   ├── en/messages.json
│   ├── ru/messages.json
│   └── uz/messages.json
├── assets/
│   ├── icons/              # icon16/48/128 + on/off варианты для setIcon
│   └── screenshots/        # скриншоты для Chrome Web Store
├── scripts/
│   └── package.sh          # сборка релизного ZIP-артефакта
├── CHANGELOG.md
├── RELEASE.md              # релизный чеклист + процесс публикации
├── QA_CHECKLIST.md         # ручной QA-чеклист перед публикацией
├── STORE_LISTING.md        # тексты для Chrome Web Store
├── PRIVACY_POLICY.md       # политика конфиденциальности
├── ENV.md
└── LICENSE
```

**Потоки данных (упрощённо):**

- `popup.js` собирает настройки из UI, сохраняет их в `chrome.storage.local`
  (ключи: `intervalSec`, `customEntries`, `useCustomList`, `profiles`, `activeConfig`,
  `configBackup` и т.д.) и отправляет команды `START`/`STOP` в service worker через
  `chrome.runtime.sendMessage`.
- `background.js` поддерживает состояние ротации (`isRunning`, `rotationTargets`,
  `ensuredWindowId`), реагирует на команды popup, восстанавливает состояние при
  `chrome.runtime.onStartup` и при «пробуждении» service worker, управляет иконкой
  (`setIcon` on/off), бейджем обратного отсчёта и ротацией вкладок.
- Popup держит `chrome.runtime.connect({ name: 'popup' })`, чтобы SW мог отличать
  «popup открыт» от «popup закрыт» и корректно ставить ротацию на паузу.

## Установка как unpacked (для разработки)

Расширение **не требует сборки**. Оно загружается напрямую из корня репозитория.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Sherzod-Norkulov/tab-rotator.git
   cd tab-rotator
   ```
2. Откройте `chrome://extensions/`.
3. Включите **Developer mode** (верхний правый угол).
4. Нажмите **Load unpacked** и выберите корневую папку репозитория (ту, где лежит
   `manifest.json`).
5. Расширение появится в списке, иконка — в toolbar браузера.
6. После изменений кода нажмите «Reload» у плитки расширения на `chrome://extensions/`.

Поддерживается Chrome/Chromium 114+ (минимум для MV3 service worker stability).
Должно работать также в Edge, Brave, Opera, Arc и других Chromium-браузерах.

## Использование

1. Кликните по иконке расширения — откроется popup.
2. Задайте **Switch interval** (интервал переключения в секундах).
3. При необходимости включите **Use only the specified list of tabs**. При первом
   открытии список уже заполняется текущими вкладками; кнопка **Load open tabs**
   обновляет его вручную, а «+ Add page» добавляет запись. Для каждой записи можно
   включить участие в ротации, указать имя, URL, индивидуальный интервал,
   автообновление и задержку перед reload. В ротации должны быть включены минимум
   две поддерживаемые страницы.
4. Дополнительно настройте:
   - **Open list tabs before start** — открывать недостающие вкладки из списка.
   - **Open list in a dedicated window** — открывать список в отдельном окне.
   - **Exclude domains** — список доменов через запятую.
   - **Never refresh these domains** — домены, где reload запрещён.
   - **Order** — sequential / shuffle.
   - **Pause rotation** — политика паузы по активности/idle-состоянию.
   - **Show timer on icon** — бейдж обратного отсчёта.
   - **Start rotator with browser** — автозапуск при старте Chrome.
   - **Rotate while popup is open** — не ставить ротацию на паузу, пока popup открыт.
5. Нажмите **Start**, чтобы запустить ротацию. Для остановки — **Stop**.
6. В блоке **Auto-refresh current page** задайте интервал и нажмите
   **Refresh this page**, чтобы создать независимую задачу обновления текущего URL.
   **Reset all** удаляет все такие задачи.

Профили (кнопки в карточке профилей):

- **Apply** — применить выбранный профиль к форме.
- **Save** — сохранить текущие настройки в выбранный профиль.
- **Save as** — сохранить настройки как новый профиль.
- **Rename** — переименовать выбранный профиль.
- **Delete** — удалить выбранный профиль.
- **Duplicate** — создать копию выбранного профиля.
- **Export JSON** — выгрузить выбранный профиль в JSON-файл; если профиль не
  выбран, выгружается текущая конфигурация.
- **Import JSON** — загрузить профиль из JSON-файла.

## Сборка релизного ZIP

Для ручной загрузки в Chrome Web Store нужен ZIP-архив с содержимым расширения.

Используйте скрипт:

```bash
bash scripts/package.sh
```

Скрипт:

- читает версию из `manifest.json`,
- валидирует, что есть обязательные файлы (`manifest.json`, `background.js`, `popup.html`,
  `popup.js`, `_locales/*/messages.json`, иконки),
- создаёт `dist/tab-rotator-<version>.zip`, исключая `.git`, `.github`, `dist`,
  `scripts`, `*.md`, редакторские файлы.

На выходе: `dist/tab-rotator-1.3.0.zip` — это артефакт для Chrome Web Store.

Требования: `bash`, `zip`, `unzip` (для self-check). На Windows используйте WSL или
Git Bash.

## Разработка

- **Линт/сборка:** отсутствуют (чистый JS/HTML без bundler). Перед коммитом
  рекомендуется вручную загрузить расширение как unpacked и прогнать smoke-тесты.
- **Debug service worker:** `chrome://extensions/` → Tab Rotator → «service worker» →
  «Inspect».
- **Debug popup:** правый клик по иконке расширения → «Inspect popup».
- **Storage:** открыть DevTools SW → вкладка Application → Storage → Extension
  Storage → Local.

## Устранение проблем

- **Ротация не стартует.** Убедитесь, что в текущем окне (или выделенном окне
  мониторинга) есть минимум 2 подходящие вкладки. Проверьте, что `customEntries`
  содержит минимум две записи с включённым `Rotate`, если включён
  `Use only the specified list of tabs`.
- **Вкладка не попала в список/не обновляется.** Системные страницы браузера и
  страницы расширений не поддерживаются для ротации/auto-refresh; используйте
  обычные `http:`, `https:` или `file:` страницы.
- **После перезагрузки браузера ротация не возобновилась.** Должен быть включён
  `Start rotator with browser`, и на момент закрытия Chrome ротация должна быть
  запущена. В MV3 service worker пробуждается асинхронно — подождите несколько секунд.
- **Иконка не меняет состояние on/off.** Перезагрузите расширение на
  `chrome://extensions/`. Убедитесь, что файлы `assets/icons/icon-on-icon*.png` и
  `icon-off-icon*.png` присутствуют.
- **Бейдж не показывает обратный отсчёт.** Включите «Show timer on icon».
- **Профиль не сохраняется.** Убедитесь, что задано имя профиля. Проверьте storage
  на квоту `chrome.storage.local` (обычно 10 MB — хватает с большим запасом).

## Приватность и разрешения

- `tabs` — читать список открытых вкладок и переключать активную вкладку.
- `storage` — хранить настройки и профили в `chrome.storage.local`.
- `idle` — определять состояние активности браузера для опциональной паузы
  ротации по активности/бездействию.

Расширение **не отправляет данные наружу** и не использует host permissions.
Подробности: [`PRIVACY_POLICY.md`](PRIVACY_POLICY.md).

## Автоматизация CI/CD

В репозитории настроены два GitHub Actions workflow:

- **CI** — `.github/workflows/ci.yml`. Запускается на каждый pull
  request в `main` и на push в `main`. Валидирует `manifest.json` и
  `_locales/*/messages.json`, проверяет формат версии и собирает
  релизный ZIP через `scripts/package.sh`, после чего публикует его
  артефактом. Workflow также объявлен как reusable (`workflow_call`) —
  его переиспользует release workflow. Подходит как required check в
  branch protection для `main`.
- **Release** — `.github/workflows/release.yml`. Запускается только на
  push в `main` (т. е. после merge PR). Сначала полностью прогоняет
  CI; если проверки прошли, читает версию из `manifest.json`,
  проверяет, что тега `v<version>` ещё нет, создаёт его и публикует
  GitHub Release с именем `Tab Rotator v<version>`, прикладывая
  `dist/tab-rotator-<version>.zip`. Release notes берутся из секции
  `## [<version>]` в `CHANGELOG.md`. Если тег уже существует, workflow
  корректно завершается без дубликата. Параллельные релизные прогоны
  сериализуются через `concurrency: release-main`.

Из этого следует простое правило выпуска: поднять `"version"` в
`manifest.json`, добавить секцию в `CHANGELOG.md`, смерджить PR в
`main` — всё остальное сделает автоматизация. Подробнее см.
[`RELEASE.md`](RELEASE.md#10-автоматизация-cicd-github-actions).
