# Manual QA Checklist — Tab Rotator

Чеклист выполняется **перед каждой отправкой в Chrome Web Store** на свежей
установке расширения (желательно — из собранного `dist/tab-rotator-<version>.zip`,
а не из dev-дерева).

Рекомендуемые браузеры для ручного QA: Chrome stable и один Chromium-derivative
(Edge или Brave).

---

## 0. Подготовка

- [ ] Версия в `manifest.json` совпадает с ожидаемой релизной.
- [ ] `chrome://extensions/` — режим разработчика включён.
- [ ] Установлена только одна копия Tab Rotator (старые версии удалены).
- [ ] Открыты DevTools service worker (чтобы видеть ошибки).
- [ ] Открыты DevTools popup (правый клик по иконке → Inspect popup).

## 1. Первый запуск (fresh install)

- [ ] После установки popup открывается без ошибок в консоли.
- [ ] Форма имеет разумные дефолты (интервал = 5 сек, список выключен).
- [ ] В футере отображается актуальная версия.
- [ ] Локализация соответствует языку браузера (ru/en/uz).

## 2. Базовая ротация по общему интервалу

- [ ] Открыть минимум 3 вкладки в текущем окне.
- [ ] Задать интервал 3 секунды, Start.
- [ ] Активная вкладка переключается каждые 3 сек, последовательно.
- [ ] Иконка меняется на «on»-вариант.
- [ ] Если включён «Show timer on icon» — бейдж отсчитывает 3, 2, 1.
- [ ] Stop — ротация останавливается, иконка «off», бейдж пропадает.

## 3. Кастомный список URL

- [ ] Включить «Use only the specified list of tabs».
- [ ] Добавить 3 записи (разные домены), задать имена.
- [ ] Start → ротация идёт только по вкладкам из списка, остальные игнорируются.
- [ ] Отключить одну из записей из списка → она исключается из ротации.

## 4. Автоматическое открытие вкладок

- [ ] Закрыть все вкладки из списка.
- [ ] Включить «Open list tabs before start», Start.
- [ ] Недостающие вкладки открываются, ротация начинается.

## 5. Отдельное окно мониторинга

- [ ] Включить «Open list in a dedicated window», Start.
- [ ] Открывается отдельное окно с вкладками из списка.
- [ ] Ротация идёт в этом окне, основное окно не затрагивается.
- [ ] Stop → окно мониторинга закрывается или остаётся (проверить поведение).
- [ ] Повторный Start корректно переиспользует/создаёт окно.

## 6. Индивидуальные таймеры и refresh

- [ ] У одной записи задать индивидуальный интервал (например, 10 сек).
- [ ] Start → на этой вкладке ротация задерживается на заданный интервал.
- [ ] Включить «Refresh» и задержку refresh у записи → вкладка перезагружается
      при переключении с задержкой.
- [ ] Добавить домен этой вкладки в «Never refresh these domains» →
      переключение происходит, но reload не выполняется.

## 6.1. Независимое автообновление текущей страницы

- [ ] Открыть обычную страницу, задать интервал 5 секунд в блоке
      «Auto-refresh current page», нажать «Refresh this page».
- [ ] Страница обновляется каждые 5 секунд независимо от запуска ротации.
- [ ] Повторное нажатие для того же URL обновляет интервал, а не создаёт дубль.
- [ ] «Reset all» очищает список задач и обновления прекращаются.
- [ ] Домен из «Never refresh these domains» не обновляется независимой задачей.

## 7. Исключения по доменам

- [ ] В поле «Exclude domains» задать `example.com`, включить Enable.
- [ ] Открыть вкладку example.com → она не участвует в ротации.
- [ ] Проверить поддомены: `sub.example.com` тоже исключается.

## 8. Shuffle

- [ ] Переключить Order в Shuffle, Start.
- [ ] Последовательность переключений не детерминирована, но все кандидаты
      участвуют.

## 9. Профили

- [ ] Save as → ввести имя → профиль появляется в select.
- [ ] Изменить настройки → Save → профиль обновляется.
- [ ] Rename → профиль переименован.
- [ ] Apply другой профиль → форма меняется.
- [ ] Export JSON → скачивается валидный JSON.
- [ ] Delete профиль → исчезает из списка.
- [ ] Import JSON (ранее экспортированный файл) → профиль восстанавливается.
- [ ] Import битого JSON → отображается понятная ошибка, расширение не падает.
- [ ] Import файла размером > 512 KB → ошибка импорта, storage не загрязняется.
- [ ] Import JSON, где `profiles` не массив или `config` не объект → ошибка
      импорта, storage не изменяется.
- [ ] Import JSON с `intervalSec: "fast"` / отрицательным / NaN → значение
      заменяется безопасным дефолтом (5 сек), ошибки не возникает.
- [ ] Import JSON с 1000 записей в `customEntries` → принято не более 500,
      расширение остаётся отзывчивым.

## 10. Pause при popup

- [ ] По умолчанию (allowRotationWhilePopupOpen = off): открыть popup во время
      ротации → ротация ставится на паузу; закрыть popup → возобновляется.
- [ ] Включить allowRotationWhilePopupOpen → ротация идёт и при открытом popup.

## 10.1. Pause по активности / idle

- [ ] Выбрать «When user is active», Start → при активном пользователе ротация
      ставится на паузу, на бейдже отображается `⏸`.
- [ ] Выбрать «When browser is idle/locked» и имитировать idle/locked состояние →
      ротация ставится на паузу и возобновляется после выхода из этого состояния.

## 11. Auto-start при запуске браузера

- [ ] Включить «Start rotator with browser», Start, закрыть Chrome.
- [ ] Открыть Chrome снова → ротация возобновляется автоматически в течение
      нескольких секунд.

## 12. Устойчивость / edge cases

- [ ] Меньше двух подходящих вкладок → ротация не стартует / не падает.
- [ ] Закрыть одну из вкладок во время ротации → ротация продолжается по
      оставшимся.
- [ ] Shuffle с двумя вкладками (пул из одного элемента) → переключение
      корректное, нет ошибок в консоли SW.
- [ ] Включить «Open list in a dedicated window» при пустом списке URL → окно
      `about:blank` **не** создаётся, ротация не стартует с ошибкой.
- [ ] Невалидный URL в записи (не URL и не домен) → либо нормализуется, либо
      пропускается; расширение не падает.
- [ ] Интервал < 1 сек → показывается ошибка, ротация не стартует.
- [ ] Пустой список с включённым «Use only the specified list» → понятная
      ошибка.
- [ ] Service worker «засыпает» и пробуждается → ротация не ломается.

## 13. Локализация

- [ ] Переключить язык браузера на `en`, `ru`, `uz` поочерёдно → UI и статусы
      переведены, placeholder'ы корректны.
- [ ] Строки не обрезаются и не выходят за карточки.
- [ ] Переключатель тёмной темы меняет тему и сохраняет её после закрытия popup.

## 14. Permissions / безопасность

- [ ] В `chrome://extensions/` → Details → расширение просит только **Tabs**,
      **Storage** и **Idle** (без host permissions).
- [ ] В popup нет `eval`, нет внешних скриптов (только `popup.js`).
- [ ] Service worker не делает сетевых запросов (вкладка Network пуста).
- [ ] Storage содержит только ожидаемые ключи (без мусора после STOP).

## 15. UI / UX

- [ ] Все чекбоксы, инпуты, селекты доступны с клавиатуры (Tab navigation).
- [ ] Нет наложений и обрезания текста на ширине 320px и 400px.
- [ ] Сообщения статусов появляются и исчезают без визуальных артефактов.
- [ ] Иконка расширения чёткая в toolbar (16px) и в `chrome://extensions/` (48px).

## 16. Финал

- [ ] В DevTools service worker и popup **нет** ошибок и необработанных
      промисов.
- [ ] В `CHANGELOG.md` описаны все заметные изменения релиза.
- [ ] `dist/tab-rotator-<version>.zip` собран из чистого рабочего дерева.
- [ ] ZIP распакован во временный каталог и проверен как unpacked — работает
      идентично dev-дереву.

Только после всех ✅ можно загружать ZIP в Chrome Web Store.
