# Tab Rotator — помощник для Chrome Web Store submission

Документ собирает ответы, которые форма публикации Chrome Web Store просит
отдельными полями при отправке расширения на ревью. Все формулировки можно
копировать напрямую. Тексты согласованы с релизом **1.3.0** и с
[`STORE_LISTING.md`](STORE_LISTING.md).

---

## 1. Single purpose description

Поле «Single purpose» в Developer Dashboard:

```
Автоматическое переключение и обновление вкладок в браузере по заданным
пользователем таймерам, с возможностью задать собственный список URL,
индивидуальные интервалы, исключения доменов и локальные профили.
```

---

## 2. Обоснование разрешений (Permissions justification)

### Permission `tabs`

```
Разрешение «tabs» необходимо для основной функции расширения — чтения
списка открытых вкладок в текущем окне и программного переключения
активной вкладки по таймеру (chrome.tabs.query и chrome.tabs.update).
Это же разрешение используется, когда пользователь включает режим
«Открывать список в отдельном окне», чтобы создать отдельное окно
браузера с заранее заданными адресами и корректно переключаться между
ними. Также оно используется для перезагрузки выбранных вкладок при
auto-refresh задачах. Без этого разрешения расширение не сможет выполнять
заявленную функциональность.
```

### Permission `storage`

```
Разрешение «storage» нужно, чтобы сохранять пользовательские настройки
между сессиями браузера через chrome.storage.local: интервал
переключения, список URL, профили, флаги автозапуска, исключения доменов,
no-refresh список, auto-refresh задачи, тему интерфейса, настройки бейджа,
паузы и порядка. Данные хранятся только на устройстве пользователя и никуда
не передаются.
```

### Permission `idle`

```
Разрешение «idle» используется только для опциональной функции паузы
ротации по состоянию активности браузера: пользователь может выбрать паузу
при активности или при idle/locked состоянии. Расширение не сохраняет
историю активности и не передаёт эти данные наружу.
```

### Host permissions

```
Расширение не запрашивает host permissions. Оно не внедряет скрипты на
сайты, не читает и не изменяет содержимое страниц. В manifest.json нет
host_permissions, content_scripts и declarativeNetRequest. Работа
ведётся только с метаданными вкладок (id, url, windowId) через API
chrome.tabs и chrome.windows.
Системные страницы браузера и страницы расширений пропускаются; ротация и
auto-refresh рассчитаны на поддерживаемые `http:`, `https:` и `file:` URL.
```

### Remote code

```
Расширение не загружает и не выполняет удалённый код. Вся логика
находится в локальных файлах расширения (background.js, popup.js,
popup.html, _locales/*). Функции eval, Function(string), динамическая
загрузка скриптов и удалённые модули не используются. Сетевые запросы
расширение не выполняет.
```

## 3. Ответы на Data Usage disclosures

Форма «Privacy practices → User data» в Developer Dashboard:

- **Personally identifiable information:** не собирается.
- **Health information:** не собирается.
- **Financial and payment information:** не собирается.
- **Authentication information:** не собирается.
- **Personal communications:** не собираются.
- **Location:** не собирается.
- **Web history:** не собирается. Расширение читает метаданные вкладок
  (идентификатор, URL, окно) только в памяти во время работы ротации и не
  сохраняет их историю.
- **User activity:** не собирается.
- **Website content:** не читается и не сохраняется. Расширение не имеет
  доступа к DOM страниц.

Обязательные декларации:

```
• Данные не передаются третьим лицам.
• Данные не используются и не продаются для целей, не связанных с
  единственным назначением расширения.
• Данные не используются и не продаются для определения
  кредитоспособности или целей кредитования.
```

## 4. Краткое резюме конфиденциальности (публичный текст)

Подходит для блока «Privacy practices → Summary» или для страницы
поддержки:

```
Tab Rotator работает полностью локально. Расширение не собирает
персональные данные, не ведёт аналитику, не обращается к сторонним
серверам и не показывает рекламу.

Что хранится локально, в chrome.storage.local вашего браузера:
• интервал переключения и флаги настроек,
• ваш список URL и имена записей,
• сохранённые профили,
• задачи автообновления и no-refresh список,
• тема popup и состояние «запущено / остановлено».

Эти данные нужны только для того, чтобы расширение помнило ваши
настройки между сессиями. Их можно в любой момент удалить, очистив
данные расширения в настройках Chrome или удалив само расширение.

Чего расширение не делает:
• не читает и не изменяет содержимое страниц,
• не отправляет данные на внешние серверы,
• не использует cookies сторонних сайтов,
• не показывает рекламу,
• не отслеживает вашу активность.
```

Полный текст политики: [`PRIVACY_POLICY.md`](PRIVACY_POLICY.md).

## 5. Заметка для GitHub Release 1.3.0

```markdown
# Tab Rotator 1.3.0

Релиз добавляет функции, закрывающие сценарии rotator/auto-refresh:
пауза по активности/idle, независимые задачи автообновления текущей
страницы, no-refresh список доменов и тёмная тема popup.

## Новые возможности

- **Пауза по активности.** Ротацию можно не останавливать, ставить на паузу
  при активности пользователя или при idle/locked состоянии браузера.
- **Auto-refresh текущей страницы.** Пользователь может создать per-URL
  задачу обновления текущей вкладки с отдельным интервалом и сбросить все
  задачи одной кнопкой.
- **No-refresh список.** Домены из отдельного списка не перезагружаются ни
  при ротации, ни независимыми задачами автообновления.
- **Тёмная тема.** Popup получил переключатель dark mode с локальным
  сохранением выбора.

## Безопасность и надёжность

- Добавлено разрешение `idle` только для чтения текущего idle/active/locked
  состояния браузера; история активности не хранится.
- Host permissions по-прежнему не запрашиваются, удалённый код и сетевые
  запросы не используются.

## Документация и релизный процесс

- Обновлены `README.md`, `CHANGELOG.md`, `QA_CHECKLIST.md`,
  `STORE_LISTING.md`, `CWS_SUBMISSION.md` и `PRIVACY_POLICY.md`.
- Скрипт упаковки `scripts/package.sh` собирает воспроизводимый ZIP для
  загрузки в Chrome Web Store.

## Миграция

Обновление безопасно: новые настройки имеют дефолты и не требуют ручных
действий. Ранее сохранённые профили продолжают работать.

## Артефакты

- `dist/tab-rotator-1.3.0.zip` — собранный архив для Chrome Web Store
  (`bash scripts/package.sh`).

Полный лог изменений — в [CHANGELOG.md](./CHANGELOG.md).
```
